# wisp 0.4.11

Fixed missing lyrics for collaborations when the track source credits one
performer but LRCLIB lists multiple performers. Artist matching now recognizes
complete names within collaboration credits, including comma-separated lists
and feat/ft credits. Exact track-title and recording-duration checks remain in place.

The fix also applies after removing an uploader suffix from a title.

## Update or install

```powershell
irm https://github.com/cmuty/wisp/releases/latest/download/install.ps1 | iex
```

Close and reopen wisp after updating. In lyrics, press F5 to retry a previous
lookup. Existing settings and collections are retained.
