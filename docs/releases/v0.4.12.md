# wisp 0.4.12

## More ways to install

- A Windows x64 EXE setup wizard with English and Russian, per-user installation, a Start menu shortcut, PATH integration, and an uninstaller. No administrator access is needed. Internet access is required for initial audio-helper setup.
- A Scoop bucket in this repository with managed mpv, yt-dlp, and Deno dependencies. Release automation updates its manifest after testing.
- WinGet manifests for `cmuty.wisp`, with an immutable EXE URL and SHA-256. Inclusion in the community catalog requires a separate submission and approval.

The existing PowerShell installer and portable ZIP remain available. Settings,
playlists, and history remain in the same local profile directory.

## Scoop

```powershell
scoop bucket add extras
scoop bucket add wisp https://github.com/cmuty/wisp
scoop install wisp/wisp
```

## EXE

Download `wisp-0.4.12-setup-x64.exe` from this release and open it.
The installer is currently unsigned. See `SHA256SUMS` for the published digest.

## PowerShell

```powershell
irm https://github.com/cmuty/wisp/releases/latest/download/install.ps1 | iex
```
