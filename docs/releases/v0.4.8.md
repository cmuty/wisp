# wisp 0.4.8

The first public release of wisp: a Windows terminal music player with a
persistent command line, local playlists, synchronized lyrics, and five themes.

## Install

Run in PowerShell:

```powershell
irm https://github.com/cmuty/wisp/releases/latest/download/install.ps1 | iex
```

Then run `wisp` from any folder in PowerShell or CMD. The installer verifies
checksums and sets up the audio helpers without administrator access.

## Included

- English and Russian onboarding and interface.
- Search across enabled public SoundCloud and YouTube Music sources and local tracks.
- Playlist imports, local collections, likes, recent history, and automatic queue continuation.
- Spotify public playlist metadata import with playback matching on another source.
- Synchronized lyrics from LRCLIB or local LRC files, timing adjustment, and cache support.
- Command completion, mouse-wheel browsing, seeking, volume shortcuts, and a sleep timer.
- Aurora and Afterglow gradient themes, three quieter palettes, and an animated butterfly.

## Download details

Windows x64. The ZIP contains wisp, documentation, and dependency license notices.
The installer downloads mpv, yt-dlp, and, when needed, Deno separately from upstream.
`SHA256SUMS` covers the ZIP; `release.json` provides machine-readable metadata.
Binaries are unsigned. Provider availability varies; Spotify matching is not
native Spotify audio streaming, and public embed imports can be incomplete.
