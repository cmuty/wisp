# wisp 0.4.14

## Playback controls that follow you

- Use your keyboard's media keys for Play/Pause, Next, Previous, and Stop, even when wisp is in the background. Keyboard software can map a key or macro to these standard Windows media actions.
- Space pauses or resumes the current recording when the input is empty. F4 also works while typing a search, independently of the selected row.
- Previous follows this session's playback history and puts the current recording back at the front of the queue. `/prev` provides the same action from the command line.
- Track indicators now use compatible ASCII symbols: `>` for playing and `=` for paused.
- Updated English and Russian help and command hints.

While wisp is open, the four media transport keys control wisp. Volume keys retain their normal system behavior. The handler is released on exit. Existing profiles, playlists, and settings are preserved.
