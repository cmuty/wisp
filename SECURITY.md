# Security

Please report sensitive vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/cmuty/wisp/security/advisories/new).
If that channel is unavailable, contact the maintainer in
[Discord](https://discord.gg/wJaJHK2hFA) to arrange a private report.
Do not post credentials or personal profile data in public issues.

Include the wisp version, Windows version, reproduction steps, and impact.
Only the latest published release receives fixes; there is no response-time guarantee.

Release installers pin the application archive and downloaded audio helpers by
SHA-256. These checks detect mismatched downloads; they do not replace trust in
the release publisher. Binaries are currently unsigned.
